# Código de Conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, acolhedor e construtivo. Assédio, ataques pessoais ou discriminação de qualquer natureza não são tolerados.

Para relatar uma conduta inadequada, use o canal privado de segurança do repositório (Security → Report a vulnerability) ou contate o mantenedor pelo perfil do GitHub.
